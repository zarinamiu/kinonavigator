# КиноНавигатор

Учебный прототип рекомендательной системы фильмов с агентным потоком и объяснением рекомендаций.

## Что делает проект

Пользователь задаёт предпочтения, например: «Посоветуй фантастику без ужасов». Система разбирает запрос, формирует список кандидатов, проверяет жанры и ограничения и возвращает рекомендации с кратким объяснением.

В проекте есть четыре рекомендательных подхода:

- **Popularity** — популярность как baseline.
- **Content-based** — совпадение жанровых признаков.
- **Item-CF** — сходство фильмов по пользовательским оценкам.
- **Hybrid** — комбинация нескольких подходов.

Также реализованы LLM-router с fallback, валидатор рекомендаций, allowlist tools, краткосрочная память сессии и долгосрочный профиль пользователя.

## Запуск

Проект проверялся на Python 3.12. Из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python app.py
```

Пример запроса:

```text
Посоветуй фантастику без ужасов
```

Для использования локальной модели через Ollama установи и запусти её отдельно:

```bash
ollama pull qwen2.5:3b
OLLAMA_MODEL=qwen2.5:3b python app.py
```

Без доступной LLM приложение может использовать настроенный fallback и локальный parser.

## Данные и результаты

В приложении используется небольшой встроенный демонстрационный каталог. Он нужен для проверки логики и не является MovieLens.

Отдельная RecSys-оценка выполнена на MovieLens 100K: `seed=42`, `K=10`, 942 пользователя.

| Алгоритм | Precision@10 | Recall@10 | NDCG@10 |
|---|---:|---:|---:|
| Popularity | 0.0754 | 0.0536 | 0.0820 |
| Content-based | 0.0313 | 0.0318 | 0.0408 |
| Item-CF | 0.2357 | 0.2630 | 0.3432 |
| Hybrid | 0.1691 | 0.1719 | 0.2282 |

В основном split использовались положительные оценки `>=4`; проверка не обнаружила утечки test в train.

Дополнительный синтетический cold-item holdout: 20% фильмов, 927 пользователей. Для content-модели получены Precision@10 `0.0794`, Recall@10 `0.0742`, NDCG@10 `0.0949`; для случайного baseline — `0.0339`, `0.0285`, `0.0393`.

Эти офлайн-результаты зависят от split и параметров эксперимента и не гарантируют качество на реальном трафике. Дополнительная оценка popularity fallback измеряет operational-показатели, а не релевантность рекомендаций новому пользователю.

Результаты находятся в `report/`.

## Память и инструменты

- Краткосрочная память хранит жанры и исключения по `session_id`, имеет TTL 1800 секунд и очищается при остановке процесса.
- Долгосрочный профиль хранится в `data/profiles.sqlite`. В нём сохраняются жанровые предпочтения, а не история разговора.
- В `agent_tools.py` разрешены только явно заданные tools: доступ к произвольному shell, файлам и выполнению кода не предоставляется.

Базу данных и MovieLens-файлы не добавляйте в Git.

## LLM, фреймворки и наблюдаемость

Сравнивались локальные модели Qwen 2.5 3B, Gemma 2 2B и Llama 3.2 3B. В проведённом benchmark Qwen прошла 3/3 строгих проверок; результаты сохранены в `report/llm_runs.json`.

LangGraph и CrewAI проверялись отдельными smoke-примерами. Это не означает, что основное приложение интегрировано с этими фреймворками.

Локальные события приложения записываются в `logs/traces.jsonl`. Phoenix запускался локально, а smoke-трасса была принята сервером. Отображение трассы реального вызова приложения в Phoenix следует считать подтверждённым только после её проверки в интерфейсе.

Docker для развёртывания агента не используется. Развёртывание Милы считается выполненным; локальный VM-check на Mac — отдельная проверка.

## Тесты

Запустить unit-тесты:

```bash
python -m unittest -v
```

Последний подтверждённый результат: **47 тестов — OK**.

Дополнительные проверки:

```bash
python tools/check_memory.py
python tools/check_split.py
python tools/check_parity.py
python tools/recsys_extra_eval.py
python tools/recsys_cold_item_eval.py
python tools/e2e_scenarios.py
```

В последнем локальном E2E-прогоне прошли 9 из 10 сценариев. VM-сценарий не прошёл на Mac из-за отсутствия `/dev/kvm`; это не следует отмечать как успешную локальную проверку VM.

## Диаграммы

В `diagrams/` находятся семь C4-диаграмм и отдельная Sequence-диаграмма. Динамическая C4-диаграмма доступна в PNG и SVG; SVG можно масштабировать без потери качества.

## Основные файлы

- `app.py` — приложение, алгоритмы рекомендаций, профиль и память.
- `llm_router.py` — маршрутизация LLM и fallback.
- `agent_tools.py` — инструменты и allowlist.
- `observability.py` — опциональная отправка трасс в Phoenix.
- `agent/` и `skills/` — инструкции и описания навыков агента.
- `tools/` — проверки и RecSys-оценки.
- `diagrams/` — C4- и Sequence-диаграммы.
- `report/` — результаты benchmark и оценок.
