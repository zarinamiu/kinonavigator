# Skill: работа с предпочтениями и профилем

## Краткосрочная память
- Используй один и тот же session_id для продолжения контекста диалога.
- Не переноси предпочтения между разными session_id.
- Очищай память только для явно указанной сессии.

## Долгосрочный профиль
- Сохраняй только разрешённые жанровые предпочтения.
- Передавай точный user_id, полученный от вызывающей системы.
- Не подменяй идентификатор пользователя и не читай чужие профили.
- Для удаления вызывай `delete_user_profile`.
- Не заявляй, что данные удалены, пока инструмент не вернул успешный результат.

## Приватность
- Не сохраняй полный текст разговора в профиль.
- Не записывай секреты и чувствительные данные.
- Если профиль не найден, продолжай без него и не выдумывай предпочтения.
